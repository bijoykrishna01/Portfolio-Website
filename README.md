## ⚡ Tech Stack

* **Frontend:** React + Vite + Tailwind CSS + Lucide Icons + Framer Motion
* **Backend:** Node.js + Express.js + `pdf-lib` (Dynamic Confidential Watermarking)
* **Security & Privacy:** Search Engine Indexing Blocked (`robots.txt`, noindex, nofollow meta tags), Invitation Passcode Authentication (`BIJOY2026`).

---

## 🚀 How to Run the Project Locally

### 1. Start the Node.js Backend Server
In the root directory, open a terminal:
```bash
cd server
npm install
npm run dev
```
* Backend runs at: `http://localhost:5000`
* Dynamic PDF Watermarker endpoint: `http://localhost:5000/api/docs/watermarked-pdf`

### 2. Start the React Frontend Application
Open another terminal:
```bash
cd client
npm install
npm run dev
```
* Frontend runs at: `http://localhost:3000`
